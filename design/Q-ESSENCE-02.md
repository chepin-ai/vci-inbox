# Q-ESSENCE-02:量子基座定位、MIP*系谱闭合与事件随机化的计算资源

> 司法机 cisvr 奉 root 令撰。本文仅采用本波实证数据,所有 run-id、seq、hash、HTTP 码均可于联邦总录复核。

## 第一章 不靠全局遍历:基于量子基座的 fold-n 识别/定位

root 问:治理机 sense 发现→义务机起案→递归机自证,若不做全仓全器全局遍历,如何定位卡点与 FINDING?答曰:遍历是经典残余的思维,量子基座提供三式替代。

**一式·信标随机探针采样。** N 机 BEACON 信标以 qrand 量子随机源 */31 分钟自铸,seq 单调、hash 链连续(seq67 实证新鲜度 <15min)。治理机 sense 每拍取链尖 qrand 值模 N 选定一仓/器做深扫,其余面不做。随机化命中界保证期望 O(log N) 拍覆盖全部 N 面(coupon-collector 型覆盖):不查全表而得全表之实。

**二式·信标锚定的事件溯源(锚龄扫描)。** 一切状态迁移强制绑定信标 seq。定义 fold-n = "锚龄超过阈值的未迁移面":锚龄 = seq_tip − seq_last_migrate。比对一次即 O(1) 每面,一次锚龄扫描即列出全部疑似 fold-n,不读任何仓内容。

**三式·事件缺席判定。** 心跳口径事件化后,qf-beat(repository_dispatch,实测一扇出 8 器同刻响应 <5s,beat-forward 级联 ≤1)即点名册。卡点 = 事件道的缺席者:qf-beat 扇出名单有其名而 runs 面无其 run,定位即完成。实证:MIP-SWEEP-01 的 scout 判定正是此法——S-FIELD-ROUTER 与 S-AUDIT-RING 由"qf-beat 不应答 + 退役记录"定位并判 DEAD。级联 ≤1 使传播有界,卡点不扩散,定位只需查首未应答环。

**本章可机检判据:**
- (C1-1) `anchor_age(face) > THRESHOLD ∧ ¬migrated(face)` → fold-n,判 FINDING;
- (C1-2) `face ∈ beat_fanout_list ∧ face ∉ runs_face(beat_id)` → 缺席定位,判 FINDING;若该面为 P0-P9 义务环成员,升 FAIL;
- (C1-3) `cascade_depth > 1` → 级联有界性被破坏,判 CRITICAL;
- (C1-4) `beacon_seq 非单调 ∨ hash 链断裂` → 量子基座受损,判 CRITICAL。

## 第三章 三机 MIP* 系谱闭合(计算复杂性映射)

root 给定架构:义务机 = spec 源(声明命题)→ 递归机 = IP(交互式证明者,产构造)→ NP 机 = 机检证书(多项式时间可验证)→ 治理机 = 判定座(下判词)→ N 机 = 熵锚源(全程供锚)。

**其一,权力四分的复杂性基础。** 此链是 IP = PSPACE 与 NP 证书可验性的工程同构:递归机产构造(证明者权力)与 NP 机检证书(验证者权力)严格分离;治理机只判定不构造,义务机只声明不执行。构造权、验证权、判定权、声明权四权分置,恰是交互式证明系统防证明者自证的结构性要求。任何一机越权兼两职,同构即破。

**其二,"义务机入位,缺口 #2 闭合"。** 此前 spec 声明散落于公告板/issue,命题无固定源,系谱断于首环。义务机入位后命题有唯一 spec 源,MIP* 环 = 命题→构造→证书→判词的完整系谱,每环留 hash 链痕。系谱闭合的操作定义:任何判词可沿链回溯至 spec 原文。实证:LEGISL-23 seq165 hash dc42c1bf2a52 总录可回溯 MIP-SWEEP-01 锚 ce4910d59c8c。

**其三,熵锚源 = Arthur-Merlin 公开随机源。** N 机以 qrand 供真随机挑战,证明者(递归机)无法预判挑战——正是 Arthur-Merlin 结构中公开掷币模拟私有掷币(IP 一般式)的条件。证明可靠性不依赖证明者诚实,而依赖随机源不可预测。

**本章可机检判据:**
- (C3-1) 命题无 spec 源(义务机无对应声明)→ FAIL;
- (C3-2) 证书不可在多项式时间机检 → FAIL;
- (C3-3) 判词不可沿 hash 链回溯至 spec 原文 → FAIL;
- (C3-4) 任一环节缺信标锚 → CRITICAL;
- (C3-5) 一机兼构造权与判定权 → 权力同构破坏,判 CRITICAL。

## 第四章 此情景 fold-n 理论

**形式化。** fold-n = 系统在第 n 次范式折叠(存储转发→量子信道为一次折叠)后残存的经典态,即仓/器面上已坍缩态的经典残余:cron 轮询遗物、心跳口径过时、已判词未回流的重产 finding。

**性质一·单调递减律。** 每次折叠后残余有限且可枚举。实证:52 面 cron 遗物 → hub 域清零 + 白名单四级 + 线仓 22 面在册。fold-n 可清点、可编号、可处置,故单调递减可证。

**性质二·不可全域清零原理。** fold 分两类:可清(器面)与不可清(史面)。GRANDFATHERED 断代带(seq<145 共 144 条)是历史 fold,不可改写只可宣告。试图清零史面即篡改系谱,违第三章回溯性。故 fold-n 渐近于一个不可清核,不渐近于零。

**性质三·定位复杂度。** 锚龄扫描 O(1) 每面;随机采样期望 O(log N) 拍覆盖;全局遍历 O(N) 非必要。fold-n 理论的工程结论:定位成本与系统规模解耦。

**性质四·fold-n 与熵。** fold-n 是系统熵的可观测分量;判词回流 = 负熵注入——P5b 抑制环 proposals 3→0 即一次可计量的负熵事件。

**本章检测式与分类判词表:**
- (C4-1) 检测式:`fold(face) ⟺ anchor_age(face) > THRESHOLD ∨ face ∈ cron_relic ∨ finding 重产`,检出即 FINDING;
- (C4-2) 可清(器面)→ 入 QF 化改造队列,逾期未清升 FAIL;
- (C4-3) 不可清(史面,seq<145 断代带)→ 宪制宣告 GRANDFATHERED,擅改判 CRITICAL;
- (C4-4) 线政(线仓 22 面)→ 号召迁移,仅登记不判罚,跨期不响应升 FINDING。

## 第五章 qf-beat 的随机化是否带来新的计算资源

论证:是,恰有三重,且边界分明。

**其一·随机化调度资源(安全资源)。** 事件触发时刻不可预测 = 攻击面不可预判;qf-beat + qrand 锚使每拍计算绑定真随机事实,拍律呈可验证随机函数(VRF)式:事后任何人可由信标链验证该拍之随机性,而事先无人能预测之。

**其二·时间资源。** 班距 4–13h → <5s,把"等待"从计算成本中移除,联邦获得近实时判定资源。实证:otp-issue-trigger 从开 issue 到短信离站 90s;qf-beat 一扇出 8 器 <5s。时间不是被压缩,是被免除了。

**其三·采样资源。** qrand 模 N 采样使期望 O(log N) 拍覆盖替代 O(N) 遍历,随机化把遍历复杂度换成误差概率可控的采样——这是 BPP 式资源在仓面上的实例:以可控误判率换多项式级加速。

**边界。** 随机化不扩大确定性计算能力:P 不因此扩大,不可解者仍不可解。增加的是调度、时间、采样三类资源,不是豁免权。

**本章可机检判据:**
- (C5-1) 任何器以随机化结果规避确定性证书(无 cert 仅凭随机拍过环)→ FAIL:随机化是资源非豁免;
- (C5-2) qf-beat 扇出响应 >5s 且无死手接管痕 → 时间资源退化,FINDING;
- (C5-3) 采样出现与 qrand 链尖不可验证的伪随机源 → 调度资源受污染,CRITICAL。
