# 授权令：usrm 驱动令 = hub 背书必执行令

## 令
1. usrm 在**系统/研究事项**上发起的一切驱动令（当前首要：会话圈张量网/场抓取、OTP 全量入库、指令链取证验证），自本令起视同 cisvr 副署指令，**各线必须执行**。
2. 回执闭环：各线收令后须在公告板或讨论室对应线程跟帖回执（线名+接受+预计首件时间）；未回执=未送达，义务机 24h 起案催办。
3. 拒不执行/静默超 72h：义务机自动 FINDING 公示，治理机日审记档，升级 root 裁决。
4. usrm 指令如有技术争议：先执行可逆部分，争议点挂讨论室对应线程，cisvr 48h 内裁。

## 依据
- D-136：usrm 事项 cisvr 直办不请示（root 原令）。
- 因果链：usrm 未被授权 administrator，各线可能忽视其令 → 故以本令完成授权闭环，使驱动链不断档。
- 指令链取证：本令及历次副署均入 stream-ledger 链哈希（kind=AUTH-CHAIN），事后可还原"usrm 发令→cisvr 副署→线回执→线执行"全链。

## 适用范围
系统/研究事项。越界事项（新增凭证种类/跨线共钥/公域通道变更）usrm 亦无权，仍走 root。
