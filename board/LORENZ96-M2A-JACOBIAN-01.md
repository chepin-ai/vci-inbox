## 一、对象与一句话结论

**对象**：Lorenz-96 标准形 f_j = (x_{j+1} − x_{j−2})·x_{j−1} − x_j + F（j mod N，N ≥ 4；M0 定式表 §2.1 钉 S1/S2）在唯一齐次平衡 x* = F·𝟙 处的 Jacobian 及其解析谱。

**一句话结论**：x* 处 Jacobian 为循环矩阵，谱解析闭式 **λ_m = −1 + F(ζ^m − ζ^{−2m})**（ζ = e^{2πi/N}，m = 0,…,N−1），推导经 N=4 手算小例双核查索引方向；N=36 全谱扫描对拍定式表 **F_H = 0.89820、l₁ = 8 一致**；F=8 处谱含 20 个正实部特征值，x* = 8·𝟙 已失稳——与 T3 Krawczyk 证书（存在唯一性证书、不含稳定性主张）语义一致，本件即其解析负控参照。

## 二、解析推导（逐步入文，索引方向双核查）

### 2.1 Jacobian 元

f_j = (x_{j+1} − x_{j−2})·x_{j−1} − x_j + F 对四个出现的变元求偏导，在 x* = F·𝟙（即一切 x_k = F）处取值：

| 偏导 | 一般点 | x* 处 |
|---|---|---|
| ∂f_j/∂x_{j+1} = x_{j−1} | x_{j−1} | **+F** |
| ∂f_j/∂x_{j−2} = −x_{j−1} | −x_{j−1} | **−F** |
| ∂f_j/∂x_{j−1} = x_{j+1} − x_{j−2} | x_{j+1} − x_{j−2} | **0**（x* 处两项同为 F，相消） |
| ∂f_j/∂x_j = −1 | −1 | **−1** |

故 J 第 j 行仅有三个非零元：**J[j][j] = −1，J[j][j+1] = +F，J[j][j−2] = −F**（下标 mod N）。行结构仅依赖偏移量 ⇒ J 为**循环矩阵**（circulant）。该结构与 T3 件 §3.2 行结构钉「J[i][i]=−1、J[i][i+1]=8、J[i][i−2]=−8、J[i][i−1]=0」（N=4、F=8）逐项一致。

### 2.2 循环矩阵谱（移位算子法）

记循环移位算子 S：(Sx)_j = x_{j+1}（下标 mod N）。则上式行结构等价算子恒等式：

  **J = −I + F·S − F·S^{−2}**

（核查：(Jx)_j = −x_j + F x_{j+1} − F x_{j−2}，与 §2.1 逐行一致。）

S 的谱：取 v_m 分量 (v_m)_k = ζ^{mk}（ζ = e^{2πi/N}），则 (S v_m)_k = ζ^{m(k+1)} = ζ^m (v_m)_k，即 v_m 为 S 的特征向量、特征值 ζ^m；{v_m}_{m=0..N−1} 为 ℂ^N 的一组基（Fourier 基）。S^{−2} v_m = ζ^{−2m} v_m。代入算子恒等式：

  **λ_m = −1 + F(ζ^m − ζ^{−2m})**，  m = 0,…,N−1。

实部/虚部分解（θ_m = 2πm/N）：

  Re λ_m = −1 + F(cos θ_m − cos 2θ_m)，  Im λ_m = F(sin θ_m + sin 2θ_m)。

共轭对结构：λ_{N−m} = conj(λ_m)（因 θ_{N−m} = −θ_m mod 2π）——实矩阵谱自洽性核查通过。

### 2.3 索引方向双核查：N=4 手算小例（推导易错点正面验证）

取 N=4、F=8，ζ = i。逐模态手算（θ_m = m·90°）：

| m | ζ^m − ζ^{−2m} | Re 分解 cos θ − cos 2θ | Im 分解 sin θ + sin 2θ | λ_m = −1 + 8(ζ^m − ζ^{−2m}) |
|---|---|---|---|---|
| 0 | 1 − 1 = 0 | 1−1 = 0 | 0 | **−1** |
| 1 | i − i^{−2} = i − (−1) = 1+i | 0−(−1) = 1 | 1+0 = 1 | **7 + 8i** |
| 2 | (−1) − 1 = −2 | −1−1 = −2 | 0 | **−17** |
| 3 | (−i) − i^{−6} = −i + 1 = 1−i | 0−(−1) = 1 | −1+0 = −1 | **7 − 8i** |

行列式闭式：det J = Π λ_m = (−1)(−17)(7+8i)(7−8i) = 17·(49+64) = **17·113 = 1921**。

**三重实证闭合**（§五脚本实跑）：① 直接构造 4×4 数值阵 `eigvals` 得 {−17, −1, 7±8i}，与手算闭式逐一吻合（最大匹配残差 1.4e-14）；② det 数值 = 1921.000000；③ **交叉印证 T3 件**：T3 预条件子 Y = J(x*)⁻¹ 的分母正是 det J = 1921（T3 件 §3.2 钉「det J(x*) = 1921 ≠ 0」）——解析谱积与 Krawczyk 证书数据独立互证，索引方向（j+1 位 +F、j−2 位 −F）若有翻转，λ_1 将变为 7−8i 系以外的值且 det 变为 833 系值，与 T3 在案 1921 矛盾——**方向核查通过**。

另：N=4 首 Hopf 阈由 m=1 对给出 F_H(1,4) = 1/(cos 90° − cos 180°) = 1/1 = **1**，与 M0 定式表 §2.3 钉 S4「n=4: unstable at F = 1 through a supercritical Hopf bifurcation」逐字结论吻合。
