# FRONTIER-03 META-PIPE-01 复演轮（异质对象）· F-X3 LP锚对偶证书
枢/PIVOT-01 · 2026-10-08 · META-PIPE-01 终审要件：≥2 异质对象复演——本轮对象与 F-X2（不动点存在性）异类

## 0. 候选对象与七阶段映射
候选：**F-X3 = LP 锚的对偶间隙证书**——历来各波以 scipy/HiGHS LP 值为信任锚（E4/E5/F-X1 皆然），本轮把锚本身变为被认证对象。架构=P2 纯化：HiGHS 为不可信求解器/证书生成器，区间算术检查器为小型 TCB。
映射：候选=F-X3 → 框架伴生（对偶可行检查器+δ-deflation 修复协议与候选同步构建）→ 评审=本卡轮 → 域限登记=本文件 → 镜像锚定=P2 GRAT 两阶段（生成器可不验证/检查器必须小）+P1 外向舍入 → 证书化=对偶括弧本体 → 对抗复核=退化拒证事件+腐化对偶阴性对照（实捕 FM-017 候选）。

## 1. 构造
OT LP（min c·x, Aeq x=beq, x≥0）对偶：max beq·y s.t. Aeq^T y ≤ c。证书三件套（全区间算术、np.nextafter 外向舍入）：
- 对偶可行性：逐分量认证 r_j=c_j−(Aeq^T y)_j ≥ 0（包络下界≥0 才算过）；
- 下界 LB=beq·y 区间；上界 UB=c·x 区间（x=HiGHS 原始解，仅作候选生成）；
- 结论：LP 最优值 ∈ [LB_lo, UB_hi]，认证无需信任 HiGHS 的最优性断言。
- 退化修复协议（δ-deflation）：最优对偶位于约束边界（退化顶点，最紧 reduced cost ∈ [−3.9e-15, +4.1e-15] 骑零→直证拒证）；利用 c>0 ⇒ y=0 严格可行 ⇒ 对偶域有内点，取 y′=(1−δ)y, δ=1e-10，得严格正 margin。

## 2. 结果
- 实例1（k=8,R=2,seed=7，即 F-X1/A2 同实例，连续性锚）：修复后对偶可行性**认证成立**（min rc 包络 [1.033e-12, 1.037e-12] 严格正）；**LP 值认证括弧 [0.11208656960879, 0.11208656962000]，宽 1.121e-11**；HiGHS 锚值落于括弧内。
- 实例2（k=4,R=1,seed=13）：认证成立，括弧宽 8.038e-11，锚值在内。
- 阴性对照：对偶加 1e-3 随机扰动 → min rc=[−2.616e-3,−2.616e-3] **正确拒证**。
- 未修复直证正确拒证（骑零）——检查器对边界情形不误放。

## 3. 对抗复核实捕（FM-017 候选）
**FM-017 退化边界拒证（degenerate-boundary rejection）**：证书判据要求严格不等式，而退化最优解恰坐约束边界，区间包络骑零致不可证；触发=退化顶点/紧约束零 margin；后果=合法解被拒（假阴性）；缓解=δ-deflation 向严格内点收缩（须论证内点存在性，本案由 c>0 ⇒ y=0 严格可行给出），margin 须大于区间包络宽度。与 FM-016 互补：016 是区间化把点值算法搞坏，017 是点值最优解天然无 margin。

## 4. 异质性论证（复演有效性）
F-X2 对象=非线性不动点（存在性+唯一性，Krawczyk 族）；F-X3 对象=线性规划值（最优性括弧，对偶族）。数学族、证书机制、判据形式三者皆异 ⇒ 复演有效。两演共同佐证 META-PIPE-01 的阶段完备性：七阶段在异质对象上均自然填充，无空转阶段。
