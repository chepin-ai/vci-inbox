## 三、语义重铸文 v0（三件套之一）

### 3.1 重铸陈述（登记层语言，v0）

**W-NS-03（重铸）**：在 2D Navier–Stokes（涡量形式、周期盒、模板参数族）上，交付两件之合取——

1. **NK 时空管（有限窗后验严格管）**：存在显式常数 r₀ > 0 与时间窗 [0,T]，使真解 ω̃ 与数值时空多项式 ω̄ 满足 sup_{t∈[0,T]}‖ω̃(t)−ω̄(t)‖_{L∞} ≤ r₀；判别机制为 Newton–Kantorovich 界组（Y、Z₁、Z₂(r)）在时空联合加权 ℓ¹ Fourier–Chebyshev 系数 Banach 代数上的逐段判别式（模板参数钉：ν=0.2、N₁=15/N₂=10、73 个 h=0.03 步 + 0.72 末步、r₀=4.54×10⁻⁵，Cadiot–Lessard Thm 4.5）。**常半径时空管 ≠ 轨道包络**：r₀ 不随 t 变化，本件不交付 t 的函数型轨道包络。
2. **捕获区全局化（集合层全局结论）**：存在显式捕获盒 X_box(σ₀,σ₁) 与衰减率 ε > 0，使解在有限窗末进入 X_box 并滞留，且范数以 e^{−εt} 一致指数衰减至 0（机制：带 e^{εt} 衰减权的 Picard 型算子在捕获盒上的收缩不动点，模板 Lemma 4.2 / Corollary 4.3 / Remark 4.4）。本结论为**集合层结论（落入并滞留 + 指数衰减率），不给逐时刻轨道距离**。

**语义定位（不变式）**：NK 段把 W-NS-02（非轨道包络）先验解析界所缺的「前 T 时间单位内轨道位置」升级为后验严格管；捕获区段与 W-NS-02 属同一先验族（Remark 4.4 自将捕获区阈值 0.58 与 Grönwall 直接估计 0.5 并列比较），二者互补合龙、填其 a-posteriori 缺口。重铸后与周期轨道包络在见证层**分开记账**，不得混引。

### 3.2 与联邦既有成果的层位关系（C1 落条）

本重铸虽面向 2D NS PDE 实例，其联邦交付层登记为**见证层数值证书 + Lean 证书锚定端点**，不构成 PDE 层定理宣称；既有包的全部定理级成果严格位于**有限维 ODE 截断层**（7 项形式化证明，Lean4，零 sorry），见证层 2 项数值实证（携「非轨道包络」披露），四项 BLOCKED(B1)——重铸不改动该层位记账，不将有限维 ODE 截断层 DONE 外推为 PDE/3D 本体陈述。2D 全局存在系 Lions–Prodi 经典结果，本证书为构造性方法学复现 + 新实例（论文 §4.1.1 自述）。
