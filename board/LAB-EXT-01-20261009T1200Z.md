## B. Lean 生态新成果/基础设施侦察（截至 2026-10）

- B1 **Axle / Axiom Lean Engine**（arXiv:2606.26442，2026-06）：云端 Lean 4 证明验证/操纵/抽取服务。14 个元编程工具；多租户按请求隔离；多版本 Lean/Mathlib 并发；Python SDK + CLI + Web + MCP + HTTP API；公开免费（axle.axiommath.ai）；已服务 5 亿请求；Axiom Math 基础设施（Putnam 2025 12/12）。**免本地安装**——直接解开本会话的环境封锁约束。
- B2 **lean4checker 已并入 Lean 本体**（原独立仓库 deprecated，2026-03）：`lake exe lean4checker --fresh Mathlib` 重放全部常量入全新环境，检测 environment hacking（元编程绕过内核加未检定理）；官方推荐进 CI。
- B3 **Lean4Lean**（Carneiro，TYPES 2025 / arXiv:2403.14064v3）：用 Lean 写的 Lean 外部 typechecker，第一个非 C++ 参考实现的完整 Lean 4 检查器；可查全部 Mathlib（慢 20-50%，Mathlib 58.79min vs C++ 44.54min）；已因此发现并修复 1 个内核 soundness bug。配套 lean4export 导出格式。
- B4 检查器堆叠现实存在：C++ 内核 → lean4checker（内置重放）→ Lean4Lean（独立外部）→ comparator（Lean FRO gold-standard 判定器）→ SafeVerify（AxiomProver 验证管线用）。**五级堆叠已是工程现实**。
- B5 Mathlib 规模（2026）：274,045 定理 + 130,791 定义，772 贡献者，2025-08 单月 >1,100 PR 合并。Lean 4.30.0（2026-05）：grind/sym 自动化增强。
- B6 FLT 项目（Buzzard-Taylor，EPSRC 资助至 2029）blueprint 驱动形式化持续推进。
- B7 **leancert**（github.com/alerad/leancert，2026-01）：Lean 4 验证区间算术库。有理/双分/仿射区间求值；exp/log/sin/cos/sqrt/atan/atanh/erf 超越函数；检查型自动微分+全局界证书；**根存在/排除/Newton 式唯一性/自动或手动 Krawczyk 系统根证书**；精确有理多项式积分；稳定 API（LeanCert.evalInterval / evalInterval_correct）。
- B8 **Mathlib.Computability.Halting**：含通用部分递归函数、**Rice 定理**、停机问题（Carneiro，ITP 2019 起在库）。
- B9 **LP 对偶形式化**：madvorak/duality（arXiv:2409.08119，Lean 4.11+Mathlib）——Farkas 类定理族 + LP 强对偶（Bartl 推广）全形式化，仅用 propext/Classical.choice/Quot.sound 三标准公理；prove2.me 已挂 SmaleNinth.lp_strong_duality（2026-09，Mathlib 0df444a / Lean v4.33.1）。弱对偶为强对偶直接推论。
- B10 AI×Lean 工业化：Axiom Math（Axle）、DeepSeek-Prover 系、AlphaProof 系；prove2.me/Palomar/TauCeti 形式化制品登记库运作中。
