# A2-CAP3999-EXPERIMENT-01 — FINDING-20261025-04 决定性受控实验

日期：2026-10-26
实验区：/mnt/agents/output/a2-probe/（已清理）；全程未写 vci-inbox 仓与 weave/pulse（仅只读计数/stat）

## 判定

**假说证实（带重要修正）**：portal 单目录 **readdir 列表封顶恰好 3999 条**，确定性复现；但机制是**列表截断而非逐出/删除**——超出文件真实存在、可 stat、可读全文，只是不出现在目录列举中。weave/pulse「蒸发」算术（4408 tracked vs 3999 visible，差 409 = 4408−3999）与该机制精确相容。

## 实验 A：平层写入 4100 件（f-00000..f-04099，64B 随机）

- 写入耗时 4.3s（portal 写速正常，无慢写）。
- 写完瞬态：ls=3824（readdir 分遍假象，证实三遍计数纪律必要）；10s 后稳定。
- **稳定态三遍（ls / find / os.listdir 互证，间隔 10s+）：恒 3999**。
- 缺失集合 = f-03999..f-04099，恰好连续 101 件 = 4100−3999。
- **关键判别**：缺失文件 `stat` 全部存在、可读出完整 64B → 不是逐出，是**列表截断**。
- 加压判别：续写 f-04100 及 f-04200..f-04299（总 4201 件），沉降后仍钉 3999，缺失扩展为名序尾部 202 件（f-03999..f-04200）。
- **排序判别**：写入 `a-zzzzz`（名序最前），沉降后它可见、f-03998 跌出列表、总数仍 3999 → **截断按名序（字典序）保留前 3999 条；非 LRU、非写入序 FIFO**。
- **瞬态过冲**：写入后 ~20–45s 窗口内列表计数可暂时高于 3999（观测到 4002/4003/4040/4088），随后确定性沉降回 3999。封顶只在稳态精确成立。

## 实验 B：对照分片 2×2050（sharded/{s0,s1}）

- 写入 4.9s；三遍计数（间隔 10s，含写后 20s 沉降）：s0=2050、s1=2050 恒稳定，无波动。
- 结论：封顶为**每目录**维度；分片可完整规避。

## 实验 C：weave/pulse 现状钉（只读）

- 三遍（间隔 10s）：`git ls-files weave/pulse | wc -l` = **4408**；`ls weave/pulse | wc -l` = **3999**；listdir=3999。差值 **409 = 4408−3999，精确成立**。
- 可见集合 == 在册文件名序前 3999（逐名比对 True）；列表中最大名 20261022-173652.json，首个隐藏 20261022-174209.json。
- 隐藏文件 stat 检查（20261022-174209 等 4 件，shell test -e）：**全部 EXISTS** → 与实验区机制一致：文件在盘上，仅被列表截断。「D 项随 tracked 增长」即截断线后名序尾部堆积。

## 实验 D：删后重建复现

- 按名显式 unlink 4202 件（67s；portal 列表截断导致 `rm -rf` 无法触及截断线后文件，须按名删除——此本身为封顶的操作性佐证），重建后重写 4100 件（4.6s）。
- 沉降约 75s 后**再次钉死 3999**，缺失同为 f-03999..f-04099，stat 均在 → **确定性复现**。

## 逐出规律（修正表述）

无逐出。机制为：**readdir 按名序返回前 3999 条即截断**；超出项保留在文件系统，可 stat/read/write/unlink，仅列举不可见。写入后存在 ≤~75s 的最终一致性瞬态（计数可短暂 >3999 或分遍不全），稳态恒 3999。

## 对 B1 假说的影响

- 「单目录 ~3999 可见封顶」**证实**（精确值 3999，非约数）。
- 「逐出/蒸发」**证伪**：无数据丢失，weave/pulse 410 件（4408−3999=409 截断 + 其余在名序线内）均在盘上可恢复，仅需分片或按名访问。
- 修复建议：任何依赖 `ls`/readdir 的盘点在 portal 上单目录须以 3999 为截断警戒；恢复 weave/pulse 全量访问可按名序分片子目录迁移。
