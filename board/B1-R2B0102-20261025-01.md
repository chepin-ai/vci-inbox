## 四、R2B-02 · rc=124 处理分支核查与修补草案

**问题实锤**:惯用写法 `git status --porcelain | grep -c '^ D'` 在 portal 慢盘下超时被 timeout 杀(rc=124)时,grep 计数输出可能是半截结果甚至 0——**「超时」与「零 D 项」在退出码/输出上不可区分**,批末扫描可能把「未知」误登为「零」。本席批十三实测全树 status >90s rc=124;批十六复核:路径限定写法(`-- weave/`)rc=0 可用,全树写法仍高危。

**可区分探测写法(带超时捕获与告警退出码)**:

```bash
#!/bin/bash
# d-scan-probe.sh —— D 项扫描:超时/异常不得按零处理
REPO=${REPO:-/mnt/agents/output/vci-inbox}
SCOPE=${SCOPE:--- weave/}          # 路径限定,慢盘保命
TMO=${TMO:-180}
out=$(mktemp)
timeout "$TMO" git -C "$REPO" status --porcelain $SCOPE > "$out" 2>&1
rc=$?
case "$rc" in
  124|137) echo "ALERT status-timeout rc=$rc:D 项未知" >&2; rm -f "$out"; exit 42;;
  0)       : ;;
  *)       echo "ALERT status-error rc=$rc" >&2; cat "$out" >&2; rm -f "$out"; exit 43;;
esac
d=$(grep -c '^ D' "$out" || true); rm -f "$out"
echo "D_COUNT=$d"
[ "$d" -gt 0 ] && exit 44           # 有 D 项:告警退出码,非静默
exit 0
```

退出码契约:`0`=确定零 D;`42`=超时(未知);`43`=git 异常;`44`=确定有 D。收口件登记时必须引用该码,**禁止只登计数**。

**修补后的一键修复仪式脚本草案(写入件内,未部署)**:

```bash
#!/bin/bash
# weave-repair-ritual.sh —— 蒸发一键修复(草案 v1)
set -u; REPO=/mnt/agents/output/vci-inbox
# ① 探测(可区分)
out=$(mktemp)
if ! timeout 180 git -C "$REPO" status --porcelain -- weave/ > "$out"; then
  echo "FATAL 探测超时/异常,仪式中止,按未知升级" >&2; exit 42
fi
grep '^ D' "$out" | awk '{print $2}' > /tmp/repair-list.txt
n=$(wc -l < /tmp/repair-list.txt); echo "D=$n"
[ "$n" = 0 ] && { echo "clean"; exit 0; }
# ② 分批 path-limited checkout 补物化(防 argv 超限/慢盘超时)
i=0; while [ $i -lt $n ]; do
  sed -n "$((i+1)),$((i+200))p" /tmp/repair-list.txt | \
    timeout 300 xargs git -C "$REPO" checkout -- || { echo "FATAL 批次 @$i" >&2; exit 45; }
  i=$((i+200)); echo "restored $i/$n"
done
# ③ 复探闭环
timeout 180 git -C "$REPO" status --porcelain -- weave/ | grep -c '^ D' | \
  { read d; echo "post-D=$d"; [ "$d" = 0 ] || { echo "FATAL 修复未闭环" >&2; exit 46; } ; }
# ④ fsck 快检(条款草案挂点)
timeout 180 git -C "$REPO" fsck --strict > /tmp/fsck-quick.txt 2>&1 || { echo "FATAL fsck rc≠0,升 FINDING" >&2; exit 47; }
grep -iE "corrupt|missing|broken" /tmp/fsck-quick.txt && { echo "FATAL 对象库异常,升 FINDING" >&2; exit 48; }
echo "OK: $n restored, fsck clean, dangling=$(grep -c dangling /tmp/fsck-quick.txt)"
```

要点:全程 rc 语义化(42/45/46/47/48 可分辨失败级);checkout 按 200 件分批 + 每批 timeout;修复后必须复探闭环 + fsck 快检双闸;任何一级失败即停并升级,不留半修复态。
