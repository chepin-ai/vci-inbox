## 二、七条款逐条过堂（明确性／可执行性／可验证性）

**条款一（墓碑映射机制）**：明确性良——五字段语义齐备、`deletion_basis` 取值域封闭；唯「本条款草案经裁定后的条款号」系前向自指，裁定后须回填（登记，不阻）。可执行性良——§1.3 先碑后删顺序闸与 §3.4(ii) 一致，commit 级序可执行。可验证性有缺——A1「sha256 与对象库历史 blob 一致率 100%」混用两种哈希口径（内容 SHA-256 vs git blob 名，后者含 "blob <len>\0" 头），对拍算法未钉（→C-6）；A1 抽样「随机抽 ≥10」无抽样方法与独立性钉，且 P-1 验证全由执行席（B1）自证、未内置非执行席独立重演——与案 C 立规①（硬前置类销记至少 1 条非执行席独立重演）正面相接（→C-1）。A3/A4 构造性反测与 append-only 机检设计良好。

**条款二（引用豁免清单机制）**：明确性中——§2.1 豁免域限「board/ 在案文书」，仓内他处（specs/、governance/、receipts/ 等）引用是否入册未明示（→C-9）；§2.2(i) grep 模式 `2026[0-9]{4}-[0-9]{6}` 年度硬编码，跨年后系统性漏检（→C-8）。可执行性良——初始建册/增量登记/除名三条件规程闭环；§2.4 fail-closed「豁免册不可读即全停」方向正确。可验证性良——B1 diff 为空、B2/B3 构造性反测、B4 除名走查均可机检。

**条款三（与 N=168 窗接口语义）**：明确性有缺——§3.2「边界 = 名序第 169 拍起」起向未明：自名序首部数第 169 拍与 §3.1(i)「不在名序最新 168 拍之内」语义相左，应作自末尾倒数解，须消歧（→C-4）。可执行性有张力——§3.3「sha256 不一致即中止该拍删除并登记异常」隐含批内单拍跳过，与 §3.4(iii)「任一断言失败整批 abort、不允许部分生效」冲突；且 §3.3 未交叉引用条款五 §5.2(ii) 之三次复核闸（暂态 ENOENT 观望态重试）（→C-5）。枚举底唯一 git ls-files、禁 readdir 系枚举、禁通配删除，与 WQ2-5 补强①及 A3 定谳逐字对得上。可验证性良——C1 静态检查、C2 反测三连、C3 拍频抖动仿真、C4 分案核验均可执行；唯推送后无远端 tree 对拍验收（推送前双通道 VERIFIED 之外的最后一环缺失，→C-11）。

**条款四（失效与回滚）**：明确性/可执行性/可验证性三性俱良——§4.1 停用须复裁（非自动废止）合乎程序；空碑事件处置（重入豁免册＋当批起滚动挂起）闭环；双通道不可达不降级单通道放行（沿 R2B-03a）正确；回滚双轨（对象库轨/归档轨）与 sha256 对拍验收明确；§4.4 强制回滚演练 ≥1 次并入 P-1，D1–D3 可机检。无必修项。

**条款五（与振荡列举之相容性论证）**：明确性良——前提更新采用 A3 降级口径正确；可执行性良——三条件（枚举唯一 ls-files＋sha256 三次复核闸＋canary 前置）逐点可指；可验证性良——E1 条文可指、E2 三遍计数留痕、E3 禁用表述 grep 机检。唯授权基件与 §5.1 引用链停于「WQ2-1 焦点裁②限定注记」，而 J-R2 案 A 已终裁将该注记转正为裁决条文并降级 A2 表述——引用应更新至最新裁决层（→C-10，文本次新性，不阻机制）。§5.3「任一条件撤除即失效须复裁」自锁正确。

## 五、生效时点规则实操校验（倒挂风险）

规则原文：生效时点 = max(「E3 批示取得后首个批首」（J-ADJ3 案二），「P-1~P-7 全绿日」（草案条款六）)，取后者（案二 ADD1 补注（四））。两形态走查：

**形态甲 · E3 批示早于前置全绿（主倒挂形态）**：E3 批示日即满足「必要条件」，但充分性不成立——状态落入「E3 已批∧前置未绿」。风险：J-ADJ3 案二原文挂账语「E3 批示未至前维持准而待生效挂账态」**只覆盖 E3 未至形态**；E3 已至而前置未绿之形态无挂账状态名，存在被误读为「批示即生效」之实操通道——尽管补注（二）已明示非充分，但状态机缺一格即多一分误启动面。另「首个批首」之「批首」无锚定义（收口条时刻？新批首节？）。→C-2 修复：三态状态机＋挂账子态命名＋批首锚。

**形态乙 · 前置全绿早于 E3 批示（保鲜倒挂）**：P-1 验证报告、P-3 建册 diff 均为时点性证据；若前置全绿日至 E3 批示日跨度长（E3 属枢/用户亲裁轨，时序非本庭可控——J-ADJ3 案二自检 3 在案），其间草案修订、拍名引用增长、CI 行为漂移均无上闸；生效宣告若直引陈旧证据，F1「逐条件引用验收证据件名」将形式满足而实质失效。→C-3 修复：复验触发器。

**结论**：规则本体可立（max 语义＋F1/F2 双重闸方向正确），两处形态缺口由 C-2/C-3 补齐后可执行；「E3 单独不充分」之既定裁定（WQ2-4 随裁登记＋案二 ADD1 补注（二））与草案条款六一致，本庭确认维持。
